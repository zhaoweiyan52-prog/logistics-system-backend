## 7. 课程演示步骤

使用各自已经注册的客户、员工、管理员账号；密码只在网页输入。新电脑先按 README 配置独立 MySQL；已有业务库不重建，不运行初始化管理员步骤。

1. 客户登录，寄件页填收件人、目的地、物品和重量，下单。记录实际运单号；订单页和轨迹应能查询，刷新后仍存在。
2. 退出客户，员工登录，待办中找到该运单。待揽收更新为运输中，再从新待办更新为派送中；轨迹应增加。此处演示教学任务池，不能声称地址是真实寄件地址。
3. 派送中上传 1 张 PNG/JPEG 合成签收图片（≤2 MB、长宽≤4096），确认“有凭证”。上传不自动签收；不要重复上传同一任务。
4. 退出员工，客户登录，在订单/轨迹查看教学签收码，先尝试错误码再输入正确码；签收后状态为已签收。提交一次反馈，再查看已保存反馈；刷新确认结果。
5. 退出客户，管理员登录，查看全局仪表盘和月度报表。设置页保存经小组同意的课程展示内容，刷新确认落库。用户角色/启停演示仅使用指定测试账号，不能禁用或降级最后一位启用管理员。
6. 换回客户核对本人订单和通知；另一个客户不应看到该订单。说明库存与订单独立，如演示出入库，使用合成物品一进一出，不动现有库存。

这是待现场按部署版本执行的验收脚本，不是本轮已经完整浏览器执行的记录。V01–V03 的第二轮结论见下节；仍需在部署后用对应提交核对线上页面与接口。
